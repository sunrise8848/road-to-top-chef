# 灶边

一个用于收录短视频教程、整理个人菜谱并在厨房逐步跟做的本地 Web 应用。

## 使用

直接双击 `index.html` 即可打开。数据通过 `localStorage` 保存在当前浏览器中。

## 已实现

- 菜谱搜索和标签筛选
- 常做菜收藏
- 文字教程待整理箱
- AI 自动整理食材与制作步骤
- AI 估算每份热量并在菜谱封面展示
- 菜谱二次编辑与自定义封面
- JSON 数据备份、导出与跨设备导入
- 菜谱详情、食材清单和个人调整
- 全屏逐步做饭模式
- 步骤计时器
- 完成次数记录
- 移动端适配

## AI 菜谱草稿

项目支持粘贴教程文案、视频字幕或自己的文字记录，由 Cloudflare Worker 安全调用 DeepSeek，整理成结构化菜谱草稿。保存后可以再次编辑菜名、食材、步骤、备注和封面图。

封面图仅用于菜谱展示，不参与 AI 识别；浏览器会先压缩图片，再保存到当前浏览器的 `localStorage`。

## 跨设备迁移

在侧栏点击“导出备份”可以下载包含菜谱、待整理教程和自定义封面的 JSON 文件。在另一台设备打开应用后，点击“导入备份”并选择该文件，即可替换当前浏览器中的数据。
