# 灶边

一个用于收录短视频教程、整理个人菜谱并在厨房逐步跟做的本地 Web 应用。

## 使用

直接双击 `index.html` 即可打开。数据通过 `localStorage` 保存在当前浏览器中。

## 已实现

- 菜谱搜索和标签筛选
- 常做菜收藏
- 文字与多图教程待整理箱
- 菜谱详情、食材清单和个人调整
- 全屏逐步做饭模式
- 步骤计时器
- 完成次数记录
- 移动端适配

## AI 菜谱草稿

项目支持粘贴教程文字或一次上传最多 6 张菜谱图片。浏览器会先压缩图片并保存在本地 IndexedDB；整理时，Cloudflare Workers AI 逐张识别图片中的文字、食材和步骤，再由 DeepSeek 合并为结构化菜谱草稿。不再读取或抓取小红书、抖音分享链接。
